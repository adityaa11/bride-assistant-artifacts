## Fixture and accessibility observations

- `/admin/catalogue` shows eight items and two bundles; tabs, search and type filter remain local UI state. `/admin/packages` shows three packages with fixture price, duration, bundle, and expanded item fields. The long-title scenario uses only source phrase fragments in a typed fixture and wraps inside its card.
- `/admin/catalogue/empty` and `/admin/packages/empty` use zero-record typed scenarios; error routes use zero-record error scenarios; proposed-result routes display explicit non-authoritative feedback. No initialization or durable seed occurs.
- Native required-field validation keeps the item dialog open on an empty name. Focus is visible; dialogs close with Escape; controls have labels and keyboard operation. Playwright checks route state, search/filter counts, result reset after reload, source grid widths, four shared-frame widths, and no horizontal overflow.
- Source scan of the T13 runtime files found no `innerHTML`, `dangerouslySetInnerHTML`, inline handler/script, `localStorage`, `sessionStorage`, `fetch`, or executable reference path. `npm run check` and `npx playwright test tests/m1-t13.visual.spec.ts` passed before the code commit.
