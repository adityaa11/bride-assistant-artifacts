# Milestone Map and Dependency Spine

| Milestone | Observable outcome | Advances | Gate |
| --- | --- | --- | --- |
| M1 | Reviewable responsive public/customer/admin UI against typed fixtures | Discovery and workflow clarity | Fixture/UI review |
| M2 | Persistent auth, authorization, migrations, adapters, and approved production choices | Trusted identity/data foundation | D-01/D-02 and protected-boundary tests |
| M3 | Authoritative catalogue, booking, snapshots, official transitions, and date protection | Core booking integrity | Same-record/snapshot/concurrency evidence |
| M4 | Private evidence, exceptions, and governed publishing | Proof flexibility, privacy, exceptions/content | D-03 and privacy/publication evidence |
| M5 | Release candidate with product and operational evidence | All acceptance outcomes | Go/no-go review |

`M1 → M2 → M3 → M4 → M5`; M4 exception/content branches can run in parallel after their stated M3/M2 prerequisites. Detailed graphs are authoritative in each milestone file.
